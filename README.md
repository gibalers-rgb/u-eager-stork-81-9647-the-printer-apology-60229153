## Run it

```sh
node main.ts
```

This writes the apology to `/output/entry.txt`. The program scores seven candidate lines against the judge's own criteria (genuine printer apology first, then funny with the punch at the end, then printer truth, then freshness, then economy), picks the best deterministically, checks the gate itself first (1–120 characters, not only whitespace, a single line), then reads the file back to confirm what landed.
